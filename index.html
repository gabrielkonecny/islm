Goods-market adjustment after an increase in G

G ↑ Z ↑ Y ↑ C ↑ I ↑
0.35
0.20
Consumption: C = c₀ + c₁(Y−T)
Investment: I = d₀ + d₁Y − d₂i
Demand: Z = [c₀ − c₁T + d₀ − d₂i + G] + (c₁ + d₁)Y
Intercept: c₀ − c₁T + d₀ − d₂i + G
Slope: c₁ + d₁
Changing c₁ changes both the intercept and the slope of ZZ. Changing d₁ changes only the slope.
Note: In this simple model, all of the rounds happen instantaneously, because the model does not explicitly include time.
